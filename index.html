Cost and data strategy

  • Meals are persisted in `nutrition-api/data/meal_log.xlsx`.
  • Local nutrition database handles common foods at zero API cost.
  • GPT-4 can be prioritized for better estimate quality (higher cost).
  • Unknown food results are cached in backend to reduce repeated calls.
  • Manual calories/protein entry can skip API estimation.
  • Image upload is stored as a note for now and not analyzed by default.
